# 股票策略回测系统

一个功能完善的股票策略回测系统，支持双均线策略和布林带策略，提供命令行和Web界面两种使用方式。

## 功能特性

### 核心功能
- **数据获取**：通过 akshare 获取A股日线数据（前复权）
- **策略回测**：支持双均线策略和布林带策略
- **参数优化**：网格搜索寻找最优策略参数
- **交叉验证**：滚动向前验证，评估策略泛化能力
- **过拟合评估**：多维度评估策略过拟合风险

### 交易机制模拟
- **手续费**：模拟真实交易手续费
- **滑点**：模拟买卖时的价格滑点
- **止损止盈**：支持设置止损和止盈阈值
- **涨跌停限制**：自动识别涨跌停，限制交易
- **ST股票识别**：自动识别ST股票，涨跌幅限制±5%
- **停牌处理**：自动处理停牌股票

### 数据优化
- **智能缓存**：历史数据缓存7天，近期数据缓存1天
- **股票搜索**：支持股票代码和名称搜索
- **数据复权**：自动使用前复权数据

## 使用方法

### 命令行方式

#### 1. 基本回测
```bash
python main.py -s 600519 -strategy dual_ma
```

参数说明：
- `-s`：股票代码（支持6位数字代码，如 `600519`）
- `-strategy`：策略类型（`dual_ma` 或 `bollinger`）
- `-start`：开始日期（可选，默认 `20230101`）
- `-end`：结束日期（可选，默认 `20241231`）

#### 2. 参数优化
```bash
python main.py -s 600519 -strategy bollinger -optimize
```

#### 3. 交叉验证
```bash
python main.py -s 600519 -strategy bollinger -validate
```

### Web界面方式

#### 1. 启动Web服务
```bash
python app.py
```

#### 2. 访问界面
打开浏览器访问：`http://127.0.0.1:8050/`

#### 3. 使用步骤
1. 在搜索框输入股票代码或名称（如 `600519` 或 `茅台`）
2. 选择策略类型（双均线或布林带）
3. 设置开始和结束日期
4. 点击"开始回测"按钮
5. 查看回测结果和交易记录

## 策略说明

### 双均线策略
基于短期和长期移动平均线的交叉生成交易信号：
- **买入信号**：短期均线向上穿越长期均线
- **卖出信号**：短期均线向下穿越长期均线

默认参数：
- 短期均线周期：5天
- 长期均线周期：20天

### 布林带策略
基于价格波动区间生成交易信号：
- **中轨**：N日移动平均线
- **上轨**：中轨 + K倍标准差
- **下轨**：中轨 - K倍标准差

交易信号：
- **买入信号**：价格从下轨下方突破下轨
- **卖出信号**：价格从上轨上方突破上轨

默认参数：
- 窗口周期：20天
- 标准差倍数：2倍

## 回测指标

系统提供以下回测指标：
- **累计收益率**：策略总收益
- **年化收益率**：按年计算的收益率
- **最大回撤**：最大亏损幅度
- **Sharpe比率**：风险调整后收益
- **胜率**：盈利交易占比
- **交易次数**：总交易次数

## 参数优化

系统支持通过网格搜索寻找最优策略参数：

### 双均线策略优化参数
- 短期均线周期：5-30天
- 长期均线周期：10-60天

### 布林带策略优化参数
- 窗口周期：10-30天
- 标准差倍数：1.5-3.0

## 交叉验证

采用滚动向前验证方式：
- 将历史数据划分为多个训练-测试周期
- 在训练集上优化参数，在测试集上验证效果
- 评估策略的泛化能力和过拟合风险

## 过拟合评估

从以下维度评估策略过拟合风险：
1. **衰减容忍度**：测试集收益相对训练集的衰减程度
2. **参数鲁棒性**：最优参数附近的参数表现稳定性
3. **统计学检验**：策略收益的统计显著性
4. **泛化能力**：在不同时间段的表现一致性

## 注意事项

1. **数据来源**：使用 akshare 获取A股公开数据
2. **复权方式**：默认使用前复权数据
3. **涨跌停限制**：普通股票±10%，ST股票±5%
4. **缓存机制**：历史数据缓存7天，近期数据缓存1天
5. **风险提示**：回测结果不代表未来收益，仅供参考
