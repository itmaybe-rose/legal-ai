# ⚖️ 法律AI助手 - Legal AI Assistant

一个基于 **RAG（检索增强生成）** 技术的专业法律文档分析系统，帮助用户对上传的合同文件进行深入的法律风险分析和智能问答。

---

## 📋 项目概述

法律AI助手是一款专业的法律文档分析工具，利用大语言模型和向量检索技术，为用户提供智能的合同审查和法律咨询服务。

### 🎯 核心价值

| 价值点 | 说明 |
|--------|------|
| **专业法律分析** | 基于上传文档进行精准的法律风险识别 |
| **智能问答** | 支持自然语言提问，获取专业法律解答 |
| **合同审查** | 自动识别合同中的漏洞、风险点和不明确条款 |
| **知识检索** | 基于文档内容进行精准检索和引用 |

---

## 🏗️ 技术架构

### 技术栈

| 层级 | 技术 | 版本 | 作用 |
|------|------|------|------|
| **前端** | Streamlit | 1.30+ | 快速构建交互式Web界面 |
| **后端** | Python | 3.10+ | 业务逻辑处理 |
| **数据库** | MySQL | 8.0+ | 存储聊天历史和用户信息 |
| **向量库** | FAISS | 1.7+ | 文档向量存储和相似度检索 |
| **LLM** | 通义千问 (qwen-turbo) | - | 生成回答 |
| **嵌入模型** | 通义向量 (text-embedding-v1) | - | 将文本转换为向量 |

## 🚀 核心功能

### 1. 文件上传与处理
- **支持格式**：PDF、DOCX、TXT
- **文档解析**：自动解析并提取文本内容
- **增量更新**：支持增量添加新文件，避免重复处理
- **进度显示**：实时显示文件处理进度

### 2. 智能问答系统
- **RAG检索**：基于向量相似度检索相关文档
- **流式输出**：打字机效果的回答展示
- **上下文理解**：支持多轮对话
- **来源引用**：回答中标注信息来源

### 3. 合同风险分析
- **风险识别**：自动识别合同中的法律风险
- **条款分析**：分析关键条款的完整性和合理性
- **漏洞检测**：检测潜在的法律漏洞和风险点

### 4. 聊天历史管理
- **历史记录**：完整保存聊天记录
- **搜索功能**：支持关键词搜索历史对话
- **跳转定位**：快速跳转到指定对话
- **导出功能**：支持JSON和TXT格式导出

### 5. 文件管理
- **文件列表**：查看已上传的文件
- **文件删除**：删除指定文件
- **清空功能**：一键清空所有文件

## 🚀 安装与运行

### 环境要求
- Python 3.10+
- MySQL 8.0+
- 阿里云通义千问 API Key

### 安装步骤

```bash
# 1. 克隆项目
git clone <项目地址>
cd legal-ai-assistant

# 2. 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置环境变量
# 编辑 .env 文件：
# DASHSCOPE_API_KEY=your-api-key
# DB_HOST=localhost
# DB_NAME=legal_ai_assistant
# DB_USER=root
# DB_PASSWORD=your-password

# 5. 运行项目
streamlit run main.py
```

## 📖 使用说明

### 登录系统
1. 访问应用地址
2. 输入用户名和密码（默认：admin / 123456）
3. 点击"登录"进入系统

### 上传文件
1. 在侧边栏找到"文件上传"区域
2. 点击上传按钮或拖拽文件
3. 等待处理完成（显示进度条）

### 提问分析
1. 在底部输入框输入问题
2. 点击发送按钮
3. 查看AI的分析结果

### 搜索历史
1. 在侧边栏搜索框输入关键词
2. 点击匹配结果跳转到对应对话

## 🔄 RAG 工作流程

```
用户上传文档
    ↓
文档解析（PyPDFLoader/Docx2txtLoader）
    ↓
文档切分（RecursiveCharacterTextSplitter）
    ↓
生成向量嵌入（DashScopeEmbeddings）
    ↓
存储到FAISS向量库
    ↓
用户提问
    ↓
向量相似度检索
    ↓
构建提示词（包含检索上下文）
    ↓
调用LLM生成回答
    ↓
保存聊天记录到MySQL
    ↓
流式输出到前端
```
